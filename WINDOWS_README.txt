Dota 2 OpenDota · MAX 复盘教练 v1.9.0

1. 解压后双击 Dota2ReviewCoach-v1.9.0.exe。
2. 在“连接设置”中配置 Dota/Steam、OpenAI 或 DeepSeek、个人微信和可选的 Telegram 备用推送。
3. OpenAI 会通过官方 Responses API 联网核对 dota2.com/opendota.com；DeepSeek 不伪装原生联网，版本证据不足时会标记待校准。
4. 在“英雄训练”中选择英雄、最近 3/5/10 局以及可选的职业或高分样本。该模式复用每场自动复盘证据卡。
5. 在“每日定时复盘”中选择时间并启用。任务由无控制台 EXE 静默运行，日志位于 daily_logs/windows-scheduled.log。
6. 完整教程、隐私说明、第三方声明和更新记录请阅读仓库 README.md、THIRD_PARTY_NOTICES.md 与 CHANGELOG.md。
